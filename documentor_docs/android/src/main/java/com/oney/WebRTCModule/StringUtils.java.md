# Technical Documentation: `StringUtils.java`

**File Path:** `android/src/main/java/com/oney/WebRTCModule/StringUtils.java`  
**Package:** `com.oney.WebRTCModule`

---

## 1. Overview

The `StringUtils` class is a Java utility class within the `com.oney.WebRTCModule` package. Its primary purpose is to convert WebRTC statistics reports (`org.webrtc.RTCStatsReport`) into a formatted JSON string representation. This serialization allows WebRTC performance and connection statistics to be easily transmitted across native boundaries (such as to a React Native JavaScript environment) or logged for diagnostic purposes.

## 3. Method Specifications

### `statsToJSON(RTCStatsReport report)`

Converts an `RTCStatsReport` instance into a JSON-formatted `String`.

* **Signature:** `public static String statsToJSON(RTCStatsReport report)`
* **Parameters:**
  * `report` (`RTCStatsReport`): The WebRTC stats report generated by `PeerConnection.getStats()`.
* **Return Value:** `String` - A JSON array string representing the map of statistics key-value pairs.

#### Logic Flow:
1. Initializes a `StringBuilder` starting with an opening array bracket `[`.
2. Retrieves the statistics map from the report using `report.getStatsMap()`.
3. Iterates over each key in `report.getStatsMap().keySet()`:
   * Formats each report entry as a two-element JSON array containing the stat key and the stat object: `["<key>", { ... }]`.
   * Extracts the corresponding `RTCStats` object for the key.
   * Populates default standard fields in the JSON object:
     * `"timestamp"`: Calculated as `stats.getTimestampUs() / 1000.0` (converts microseconds to milliseconds).
     * `"type"`: Extracted via `stats.getType()`.
     * `"id"`: Extracted via `stats.getId()`.
   * Iterates through `stats.getMembers()` map (additional key-value attributes specific to that statistic) and appends each member key-value pair to the JSON object by delegating value formatting to `appendValue()`.
   * Closes the JSON object and entry array with `}]`.
4. Closes the outer JSON array with `]` and returns the constructed `String`.

---

### `appendValue(StringBuilder builder, Object value)`

Helper method that recursively formats and appends various Java object types into their valid JSON string representations within a `StringBuilder`.

* **Signature:** `private static void appendValue(StringBuilder builder, Object value)`
* **Parameters:**
  * `builder` (`StringBuilder`): The active `StringBuilder` buffer receiving JSON tokens.
  * `value` (`Object`): The object instance to serialize into JSON.
* **Return Value:** `void`

#### Handled Object Types:
1. **Arrays (`Object[]`)**:
   * Appends an opening square bracket `[`.
   * Recursively calls `appendValue` for each element in the array, comma-separated.
   * Appends a closing square bracket `]`.

2. **Maps (`Map`)**:
   * Appends an opening curly brace `{`.
   * Iterates over map entries (`Map.Entry<String, Object>`), comma-separating key-value pairs.
   * Wraps keys in double quotes and recursively calls `appendValue` on the values.
   * Appends a closing curly brace `}`.
   * **Exception Handling**: Catches `ClassCastException` if map casting fails and logs an error to `android.util.Log.e` using `TAG`.

3. **Strings (`String`)**:
   * Wraps the string value in double quotes: `"value"`.

4. **All Other Types (Primitives, Numbers, Booleans, `null`)**:
   * Directly appends the object using `builder.append(value)`.

## 4. Output JSON Structure

Based on `statsToJSON`, the generated JSON string follows this structure:

```json
[
  [
    "STAT_KEY_1",
    {
      "timestamp": 1620000000000.0,
      "type": "inbound-rtp",
      "id": "IT01B",
      "memberKey1": "stringValue",
      "memberKey2": 123,
      "memberKey3": ["arrayValue1", "arrayValue2"],
      "memberKey4": {
        "nestedKey": "nestedValue"
      }
    }
  ],
  [
    "STAT_KEY_2",
    {
      "timestamp": 1620000000000.0,
      "type": "track",
      "id": "TR01",
      "memberKey1": true
    }
  ]
]
```
