# Technical Documentation: `WebRTCModule+RTCPeerConnection.h`

**File Path:** `ios/RCTWebRTC/WebRTCModule+RTCPeerConnection.h`  
**Language:** Objective-C

---

## Overview

The `WebRTCModule+RTCPeerConnection.h` header file defines two Objective-C categories that extend existing classes to integrate WebRTC peer connection features into the `react-native-webrtc` iOS module:

1. **`RTCPeerConnection (React)` Category:** Extends WebRTC's native `RTCPeerConnection` class with custom properties required to maintain state and map native WebRTC objects to React Native identifiers.
2. **`WebRTCModule (RTCPeerConnection)` Category:** Extends `WebRTCModule` to conform to the `RTCPeerConnectionDelegate` protocol and declares a utility class method for certificate retrieval.

---

## File Imports

```objc
#import <WebRTC/RTCPeerConnection.h>
#import "DataChannelWrapper.h"
#import "WebRTCModule.h"
```

* **`<WebRTC/RTCPeerConnection.h>`:** Provides the base native `RTCPeerConnection` class interface from the Google WebRTC framework.
* **`"DataChannelWrapper.h"`:** Imports the custom wrapper structure used to manage data channel states and callbacks.
* **`"WebRTCModule.h"`:** Imports the primary module class handling communication between React Native and native iOS logic.

## Category Interfaces

### 1. `RTCPeerConnection (React)`

Extends the native `RTCPeerConnection` class with properties needed to track React Native identifiers, data channels, remote media components, and a back-reference to the main `WebRTCModule`.

```objc
@interface RTCPeerConnection (React)

@property(nonatomic, strong) NSNumber *reactTag;
@property(nonatomic, strong) NSMutableDictionary<NSString *, DataChannelWrapper *> *dataChannels;
@property(nonatomic, strong) NSMutableDictionary<NSString *, RTCMediaStream *> *remoteStreams;
@property(nonatomic, strong) NSMutableDictionary<NSString *, RTCMediaStreamTrack *> *remoteTracks;
@property(nonatomic, weak) id webRTCModule;

@end
```

#### Properties

| Property | Type / Attributes | Description |
| :--- | :--- | :--- |
| `reactTag` | `NSNumber *`<br>`(nonatomic, strong)` | Unique identifier used by React Native to associate the native peer connection instance with its JavaScript counterpart. |
| `dataChannels` | `NSMutableDictionary<NSString *, DataChannelWrapper *> *`<br>`(nonatomic, strong)` | Key-value store mapping string identifiers to `DataChannelWrapper` instances managed by this connection. |
| `remoteStreams` | `NSMutableDictionary<NSString *, RTCMediaStream *> *`<br>`(nonatomic, strong)` | Key-value store mapping stream ID strings to received remote `RTCMediaStream` instances. |
| `remoteTracks` | `NSMutableDictionary<NSString *, RTCMediaStreamTrack *> *`<br>`(nonatomic, strong)` | Key-value store mapping track ID strings to received remote `RTCMediaStreamTrack` instances. |
| `webRTCModule` | `id`<br>`(nonatomic, weak)` | Weak reference to the parent `WebRTCModule` instance managing this peer connection. Defined as `weak` to prevent strong reference cycles. |

### 2. `WebRTCModule (RTCPeerConnection)`

Extends `WebRTCModule` to adopt the `RTCPeerConnectionDelegate` protocol and provides class-level utilities related to `RTCPeerConnection`.

```objc
@interface WebRTCModule (RTCPeerConnection)<RTCPeerConnectionDelegate>

+ (RTCCertificate *)getCertificate:(NSString *)certId;

@end
```

#### Protocols Conformed To
* **`RTCPeerConnectionDelegate`:** Enables `WebRTCModule` to act as a delegate listener for state changes and events generated by `RTCPeerConnection` instances.

#### Class Methods

##### `+ (RTCCertificate *)getCertificate:(NSString *)certId;`
* **Purpose:** Class method that retrieves an `RTCCertificate` instance matching the provided certificate identifier string.
* **Parameters:**
  * `certId` (`NSString *`): The string identifier representing the desired certificate.
* **Returns:** An `RTCCertificate *` object associated with the provided ID.
