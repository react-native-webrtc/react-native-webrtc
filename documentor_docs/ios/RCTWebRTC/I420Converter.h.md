# Technical Documentation: `I420Converter.h`

## Overview

The `I420Converter.h` header file declares the `I420Converter` class interface within the iOS native component of the `react-native-webrtc` project (located at `ios/RCTWebRTC/I420Converter.h`).

The primary purpose of `I420Converter` is to provide an interface for converting WebRTC video frames formatted as I420 raw YUV planar buffers (`RTCI420Buffer`) into iOS CoreVideo pixel buffers (`CVPixelBufferRef`). It utilizes Apple's **Accelerate** framework (`vImage`) to support performant image format conversions.

## Method Definitions

### 1. `prepareForAccelerateConversion`

```objc
- (vImage_Error)prepareForAccelerateConversion;
```

* **Description:** Prepares and initializes the internal structures or context required by Apple's Accelerate (`vImage`) framework to perform conversion operations.
* **Parameters:** None.
* **Return Value:** `vImage_Error` — An error code returned by the `vImage` framework indicating success (`kvImageNoError`) or an error state during initialization.

### 3. `createPixelBufferPoolWithWidth:height:`

```objc
- (void)createPixelBufferPoolWithWidth:(size_t)width height:(size_t)height;
```

* **Description:** Allocates or configures an internal pixel buffer pool optimized for generating `CVPixelBufferRef` instances of specified dimensions.
* **Parameters:**
  * `width` (`size_t`): Target width in pixels for buffers generated by the pool.
  * `height` (`size_t`): Target height in pixels for buffers generated by the pool.
* **Return Value:** `void`

---

### 4. `convertI420ToPixelBuffer:`

```objc
- (CVPixelBufferRef)convertI420ToPixelBuffer:(RTCI420Buffer *)buffer;
```

* **Description:** Converts an incoming WebRTC I420 buffer (`RTCI420Buffer`) into an iOS CoreVideo pixel buffer (`CVPixelBufferRef`).
* **Parameters:**
  * `buffer` (`RTCI420Buffer *`): The input WebRTC I420 YUV video frame buffer to convert.
* **Return Value:** `CVPixelBufferRef` — A reference to the resulting CoreVideo pixel buffer containing the converted image data.

## Typical Usage Workflow

Based on the exposed interface methods, the lifecycle for converting frames with `I420Converter` follows these steps:

1. **Initialization / Preparation:** Call `prepareForAccelerateConversion` to set up Accelerate (`vImage`) resources.
2. **Pool Creation:** Call `createPixelBufferPoolWithWidth:height:` with the dimensions matching the input frame stream to allocate memory efficiently.
3. **Conversion:** Pass incoming WebRTC frames (`RTCI420Buffer *`) into `convertI420ToPixelBuffer:` to receive `CVPixelBufferRef` output objects.
4. **Cleanup:** Call `unprepareForAccelerateConversion` when frame conversion is no longer needed to release internal resources.
