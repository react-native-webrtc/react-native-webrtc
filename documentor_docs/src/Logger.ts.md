# Documentation: `src/Logger.ts`

## Overview

The `src/Logger.ts` module provides a structured logging utility for the `rn-webrtc` library. It acts as a wrapper around the `debug` package, categorizing log outputs into specific log levels (`DEBUG`, `INFO`, `WARN`, `ERROR`) under a standardized namespace hierarchy.

---

## Architecture & Class Definition

### Class: `Logger` (Default Export)

`Logger` is the main class exposed by this module. It manages instances of `debug.Debugger` for four severity levels and provides methods to trigger log entries.

---

## Static Properties & Methods

### `ROOT_PREFIX`
* **Type**: `string`
* **Value**: `'rn-webrtc'`
* **Description**: The top-level namespace prefix used for all loggers generated by this class.

### `enable(ns: string): void`
* **Parameters**:
  * `ns` (`string`): The namespace pattern to enable.
* **Returns**: `void`
* **Description**: Passes the namespace string to `debug.enable(ns)` to dynamically enable matching `debug` namespaces.

---

## Constructor

```typescript
constructor(prefix: string)
```

### Parameters
* `prefix` (`string`): The component- or module-specific sub-namespace (e.g., `'PeerConnection'`).

### Initialization Behavior
1. **Namespace Construction**: Combines `Logger.ROOT_PREFIX` and the passed `prefix` into a base prefix string:
   $$\text{\_prefix} = \text{`rn-webrtc:<prefix>`}$$

2. **Debugger Instances Created**:
   Constructs four separate `debug.Debugger` instances for each severity level:
   * `this._debug`: `${_prefix}:DEBUG`
   * `this._info`: `${_prefix}:INFO`
   * `this._warn`: `${_prefix}:WARN`
   * `this._error`: `${_prefix}:ERROR`

3. **Log Handler Binding**:
   Binds `console.log` directly to the `.log` property of each debugger instance (`this._debug.log`, `this._info.log`, `this._warn.log`, `this._error.log`). This ensures output is directed via standard `console.log`.

---

## Instance Methods

### `debug(msg: string): void`
* **Parameters**: `msg` (`string`) – The message to log.
* **Description**: Writes `msg` to the `DEBUG` level debugger instance (`this._debug`).

### `info(msg: string): void`
* **Parameters**: `msg` (`string`) – The message to log.
* **Description**: Writes `msg` to the `INFO` level debugger instance (`this._info`).

### `warn(msg: string): void`
* **Parameters**: `msg` (`string`) – The message to log.
* **Description**: Writes `msg` to the `WARN` level debugger instance (`this._warn`).

### `error(msg: string, err?: Error): void`
* **Parameters**:
  * `msg` (`string`) – The error message to log.
  * `err` (`Error`, optional) – An optional `Error` object.
* **Description**: Extracts the stack trace from `err` (if provided and present). Defaults to `'N/A'` if `err` or `err.stack` is undefined. Writes the formatted message string to the `ERROR` level debugger instance (`this._error`).
* **Output Format**: `${msg} Trace: ${trace}`

## Usage Example

```typescript
import Logger from './Logger';

// Enable all logs under the root namespace
Logger.enable('rn-webrtc:*');

// Instantiate a logger for a specific module
const logger = new Logger('MediaStream');

// Log messages across different severity levels
logger.debug('Initializing media stream...');
logger.info('Stream added successfully.');
logger.warn('Low bandwidth detected.');

try {
    // Operations...
} catch (err) {
    logger.error('Failed to attach stream', err as Error);
}
```
